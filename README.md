# Exercícios de JavaScript

Repositório dedicado à prática de lógica de programação e aos fundamentos de JavaScript, utilizando HTML e CSS para criar uma interface simples e interativa.

## 📚 Sobre o projeto

O projeto reúne exercícios de programação que trabalham operações matemáticas, conversões de temperatura, cálculos e estruturas condicionais.

## 🧮 Exercícios

- **Cubo de um número:** calcula o cubo de um valor informado.
- **Conversão de temperatura:** converte Fahrenheit para Celsius.
- **Área de um triângulo:** calcula a área com base e altura.
- **Área e perímetro de um círculo:** realiza cálculos a partir do raio.
- **Calculadora de desconto:** calcula um desconto de 5%.
- **Verificador de idade:** verifica a maioridade com base no ano de nascimento.
- **Calculadora de combustível:** estima a quantidade de litros e a distância percorrida a partir de um valor informado.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ▶️ Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo HTML principal em um navegador.
3. Informe os valores solicitados e utilize os botões para realizar os cálculos.

## 🎯 Objetivo

Praticar os fundamentos da programação e desenvolver familiaridade com JavaScript e sua integração com HTML e CSS.
